# Security Policy

migralint reads SQL files only. It never connects to a database or sends data anywhere.

To report a vulnerability in migralint itself, email igsoftwebstudio@gmail.com
with the subject `migralint security`. Please do not open a public issue.
You will get an acknowledgement within 48 hours.

A missed unsafe pattern is a rule gap, not a vulnerability: open an issue
titled `rule: <pattern>` with a minimal SQL sample.
